# salih1's Godot Metaverse kit

A Godot Metaverse kit, one that I use for my own Metaverse project that I focus on my spare time as a hobby.

It is also released publicly with aims to help anyone (including me) get started with their own extensive Metaverse instance. 

This project is based on, and supersedes, my earlier Metaversum-Salihanum project.

## Design Philosophy

This project is completely vibe coded according to several standards I set up for myself, and it is continuously improved as my understanding and model capacities follow up. 

These standards may not be proper to your standards, but they should be consistent. I am aiming for Linux kernel coding style adapted to this Metaverse kit, involving minimal comments, strict code and data separation, while reserving one concept per file.

## Currently Being Worked On

- **Basics**: Currently, a Godot Client and Python Script Package (Backend also serves the frontend) are provided as the main components of the game. These have been, and are still being, refactored with new standards so coding agents and humans can read them in an easier way, get things done in an easier way, and work on them in an easier way.
- **Additions**: The core is supposed to feature 3 more packages; a Legislative script package, a livestream television script package, and an operating system package. These are currently being refined on and have not been fit for a release yet.

## Getting Started

The easiest way to get started is running server/run.sh directly and connecting via client based on your method of choice.

- **Basics**: You should start by copying "client/data/identity.example.json" and "server/config/identity.example.json" to "identity.json" in the same folders, then editing them, so your instance has a shape.
